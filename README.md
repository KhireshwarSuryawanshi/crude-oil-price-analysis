# Historical Analysis of WTI Crude Oil Prices (1986–2026)

An end-to-end Data Analytics project analyzing historical WTI crude oil prices from 1986 to 2026 using Python, Pandas, Matplotlib, and Power BI.

This project focuses on data cleaning, exploratory data analysis (EDA), feature engineering, and interactive dashboard creation to uncover long-term market trends, volatility patterns, and key economic events impacting crude oil prices.

# Project Overview

The objective of this project is to analyze historical crude oil price movements and extract meaningful business insights through data visualization and analytics.

The analysis highlights:

- Long-term oil price trends
- Price volatility across decades
- Impact of global events such as:
    -2008 Financial Crisis
    -COVID-19 Oil Crash (2020)
    -Major geopolitical disruptions
-Annual average price movements
-Daily price fluctuations

An interactive Power BI dashboard was developed to visualize these insights dynamically.
